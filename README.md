📊 Top Anime Analysis Dashboard (Power BI)

An interactive Power BI dashboard analyzing the Top 500 highest-rated anime to uncover insights about genres, studios, episode counts, rankings, and release trends over decades.

This project demonstrates data cleaning, transformation, data modeling, and data visualization techniques using Power BI and Power Query.

📁 Project Overview

The goal of this project is to explore patterns in top-ranked anime and present insights through an interactive analytics dashboard.

The dashboard allows users to filter and analyze anime data by:

Genre

Studio

Decade

Key metrics such as average scores, episode counts, and ranking distribution help reveal trends in the anime industry.

📈 Key Insights

The dataset includes 500 top-ranked anime produced by 109 studios.

The average anime score is 8.43, indicating consistently high ratings.

The average episode count is 18, showing most highly rated anime are relatively concise series.

400 anime fall within the Top 500 ranking tier, while only 10 anime are ranked in the Top 10.
